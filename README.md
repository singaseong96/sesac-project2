# 개인 맞춤형 신용카드 추천 RAG 챗봇

> 사용자의 **직업·소득·라이프스타일**을 입력받아, 신뢰 가능한 출처 데이터에 근거해
> 개인 상황에 맞는 신용카드 4종을 추천하는 **RAG 기반 LLM 챗봇**입니다.

일반 LLM은 최신 카드 혜택 정보를 모르거나 잘못된 정보를 그럴듯하게 답하는 한계가 있습니다.
이 프로젝트는 그 문제를 **RAG(Retrieval-Augmented Generation) 구조**로 해결해,
모델이 추측이 아닌 **실제 카드 데이터에 근거해** 답하도록 설계했습니다.

<br>

## 핵심 설계 포인트

**"왜 이렇게 만들었는가"를 중심으로 설계한 프로젝트입니다.**

| 문제 | 설계적 해결 |
|------|------------|
| LLM이 최신 카드 정보를 모르거나 지어냄 | 카드 데이터를 직접 크롤링해 **벡터 DB에 적재**하고, 검색된 실제 데이터에 근거해 답변 생성 |
| 전체 카드를 LLM에 다 넣을 수 없음 | **리트리버 유사도 검색으로 상위 50개로 1차 후보를 압축**한 뒤, LLM이 최종 4종 선별 |
| 추천 이유가 불투명함 | 시스템 프롬프트 설계로 **카드별 주요 혜택·랭킹 정보를 함께 제공** |

<br>

## 시스템 아키텍처

```
[사용자 입력]
 직업 · 소득 · 라이프스타일
        │
        ▼
┌──────────────────────────┐
│  Retriever (유사도 검색)   │   ← ChromaDB에 적재된 카드 임베딩에서
│  상위 50개 카드 후보 추출   │      사용자 상황과 가까운 카드를 검색
└──────────────────────────┘
        │
        ▼
┌──────────────────────────┐
│  LLM (gpt-5-nano)         │   ← 50개 후보 중 사용자 상황에
│  최종 카드 4종 선별 + 설명  │      가장 부합하는 4종을 선별하고
└──────────────────────────┘      혜택·랭킹과 함께 추천 사유 생성
        │
        ▼
[추천 결과]
 카드 4종 + 주요 혜택 + 랭킹 정보
```

<br>

## 데이터 파이프라인

카드 비교 사이트에서 **TOP 100 카드**의 정보를 크롤링해 벡터 DB로 구축했습니다.

- **수집 항목:** 카드명, 카드사, 주요 혜택, 연회비, 랭킹 순위
- **저장:** 수집한 카드 정보를 임베딩하여 **ChromaDB**에 적재
- **검색:** 사용자 입력과의 유사도 기반으로 관련 카드 후보를 검색

<br>

## 기술 스택

| 구분 | 사용 기술 |
|------|----------|
| Language | Python |
| LLM | OpenAI `gpt-5-nano` |
| RAG / Vector DB | ChromaDB, Retriever 기반 유사도 검색 |
| 데이터 수집 | 웹 크롤링 (카드 비교 사이트 TOP 100) |

<br>

## 동작 예시

```
입력 예시
  직업       : 사회초년생 직장인
  소득       : 연 3,000만 원대
  라이프스타일 : 대중교통 이용, 카페·온라인 쇼핑 잦음

출력 예시
  추천 카드 4종 + 각 카드의 주요 혜택 + 랭킹 정보
  (예: 대중교통 할인 / 카페·간편결제 적립 중심 카드)
```

<br>

## 한계 및 개선 방향

실제 서비스 수준으로 발전시키려면 다음이 필요하다고 판단했습니다.

- **정량 평가셋 부재:** 추천 결과를 직접 검토했을 때 약 80% 수준에서 사용자 상황에 부합한다고 판단했으나, 정량적 평가셋 기반의 정확도 측정은 수행하지 못함 → **추천 품질을 수치로 검증하는 평가 체계 마련이 다음 과제**
- **데이터 신선도:** 크롤링 시점의 정보 기준이므로, 카드 혜택 개정에 대응하는 **주기적 갱신 자동화**가 필요
- **검색 품질:** 유사도 검색의 후보군(상위 50개) 크기와 임베딩 전략에 따라 추천 품질이 달라질 수 있어, 리트리버 튜닝 여지가 있음

<br>
